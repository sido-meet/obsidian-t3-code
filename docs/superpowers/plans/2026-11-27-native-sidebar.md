# 原生侧栏实施计划

基线为 `feat/6-sidebar-layout`。脚手架在 `feat/2-mvp-v0.1` 的提交链中，PR #13 通过远端检查。CLI 侧栏以该 MVP 为父级，按审查与授权安排合并。现有分支和 worktree 均保留。

1. 为 `src/t3/cli.ts` 增加会话列表、会话元信息和模型选项测试。验证实际会话权限、提供方、模型和链接，未知字段不得合成。
2. 为设置增加模型预设。支持选择 Provider 实例、对应模型和配置的推理强度，且已有会话可以另开并带入草稿。
3. 更新 `src/ui/ObsidianT3CodeView.ts` 与 `styles.css`。顶栏提供标题、历史、新会话，底栏提供模型、额度、权限和发送。历史恢复同一线程，草稿按会话保留。上下文显示为附加与移除控件。额度缺少数据时标记不可用，待处理时转到 T3 Code。
4. 通过隔离库检查 240、320、480 像素和深浅色状态，执行类型检查、Lint、覆盖率、构建及独立审查。
5. 未公开的 CLI 功能明确记录依赖。包括自动目录、账户额度、实时事件与审批/停止命令。插件保持 CLI-only。
