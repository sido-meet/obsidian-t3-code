# ADR 0002 — 通过 T3 CLI 接入桌面侧栏

- 状态：已采纳，适用于 `feat/6-sidebar-layout`。
- 背景：用户明确要求 Obsidian 包装本机 T3 CLI。PR #13 的协议直连方案记录保留于 ADR 0001。
- 决策：侧栏通过固定参数调用已安装的 `t3 thread list/start/send/show`。正文只进入 stdin，JSON stdout 用于显示回复、状态和线程。认证、服务发现和模型运行由 T3 Code 负责。界面采用顶部状态栏、独立滚动的消息区、底部输入框与上下文控件。
- 影响：公开 CLI 当前以轮询提供状态，没有实时事件订阅和停止命令。运行权限由 T3 项目配置决定，用户应配置「需要审批」。项目路径留空时使用当前 Vault 根目录，也可配置独立项目。关闭侧栏会停止本地读取，不会向 T3 服务发送停止任务的指令。
